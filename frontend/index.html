About

Free-flow practice · Local workspace · v0.1.0

Camera
Preview only. Video is not recorded to disk by the app. When an API key is configured, the stream is shared with the locally installed SmartSpectra SDK for on-device measurement.
Transcription
In the desktop app, speech transcription runs locally on this device with a downloaded model; audio is not sent to a cloud service. In a browser, browser speech recognition listens through your microphone and may process audio through its speech service. Timestamps are approximate recognition or transcription windows.
SmartSpectra
Blink detection is requested by default. Optional pulse rate and HRV RMSSD can be enabled in Features; only selected SDK metrics are requested. Feature changes apply to a new app session, so restart Baseline CogniSync after ending the current session. The experimental head-direction estimate is derived from SmartSpectra face landmarks and emits preview-relative direction vectors with NLP/cognitive labels once available; NLP/cognitive classification remains disabled. The app computes only coarse word-per-minute pacing from approximate transcript timing; semantic text scores and acoustic prosody are not yet calculated. SDK errors and validation statuses are exported, retryable engine failures restart the pipeline automatically (at most twice per session), and a 10 s packet gap turns the sensor chip to STALLED. Cognitive-state labels are not calculated.
API key
The Presage API key is read from the environment and is not stored in the repository or renderer bundle.
Export
The session JSON contains session metadata, transcript windows, blink events, enabled-feature and requested-metric details, optional head-direction/cardio samples, SmartSpectra diagnostics, SDK errors, and source status. Missing values stay null rather than appearing as zero. Only one app instance can own a session; a second launch focuses the existing window.

Head direction matrix

All vectors are defined from the observer's view (camera frame) of a right-handed subject. If subject handedness is set to LEFT, invert horizontal directional vectors (UP_LEFT ↔ UP_RIGHT, LATERAL_LEFT ↔ LATERAL_RIGHT, DOWN_LEFT ↔ DOWN_RIGHT).

Vector Code Observer View Direction Subject Eye Direction NLP Cue Classification Cognitive State Description Baseline Expectation
Vc UP_LEFT Up-Right Visual Constructed Imagining novel images, synthesizing unseen scenarios, or altering visual details of past events. High Cognitive Construction
Vr UP_RIGHT Up-Left Visual Remembered Accessing stored visual memories, recalling exact colors, layouts, or past visual experiences. Memory Recall
Ac LATERAL_LEFT Mid-Right Auditory Constructed Synthesizing novel sounds, formulating hypothetical dialog, or crafting deliberate verbal phrasing. High Cognitive Construction
Ar LATERAL_RIGHT Mid-Left Auditory Remembered Recalling specific auditory memories, distinct voices, known sounds, or previously heard statements. Memory Recall
K DOWN_LEFT Down-Right Kinesthetic / Tactile Processing bodily sensations, visceral emotions, tactile memories, or physical feelings. Internal Feeling
Ai DOWN_RIGHT Down-Left Auditory Internal Engaging in internal monologue, self-talk, or deliberating specific wording prior to speaking. Internal Processing

Mapping rules

  • Head direction: optional SmartSpectra face-landmark head-direction estimation can be enabled in Features. It emits preview-relative direction vectors with NLP/cognitive labels once landmark packets are received; NLP/cognitive classification remains disabled and the estimate is experimental and unvalidated.
  • Blinks: blink detection is requested by default. Stable blink-on transitions are exported as events and linked to approximate transcript windows; event rates are descriptive only, not a cognitive-state measure.
  • Cardio baseline: pulse and HRV each use the median of their first 30 seconds of stable readings; each baseline requires at least 3 samples spanning at least 15 seconds. Changes are computed only from later stable readings.
  • Cardio response candidate: set only when both post-baseline changes exist and pulse is at least 4 BPM above baseline while HRV is at least 15 ms below baseline. This provisional heuristic is not a validated stress measure or diagnosis.
  • Unavailable data: elevated_cognitive_load and biometric_congruence are not inferred; unavailable measurements and flags remain null.
